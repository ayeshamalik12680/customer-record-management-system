# Customer Record Management System

A Python-based desktop application designed to manage customer records efficiently using a simple graphical user interface.

## Project Overview

The Customer Record Management System helps users store, manage, search, update, and delete customer information. It uses SQLite for database management and Tkinter for the graphical user interface.

The application also supports importing and exporting customer records through Excel files.

## Features

- Add new customer records
- View all customer records
- Update existing customer information
- Delete customer records
- Search customers
- Store records in an SQLite database
- Import customer data from Excel
- Export customer data to Excel
- Dashboard statistics
- Input validation

## Technologies Used

- Python
- Tkinter
- SQLite
- Pandas
- OpenPyXL
